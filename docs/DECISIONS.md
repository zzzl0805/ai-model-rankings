## ADR-001 数据走云存储，不走云数据库

- **日期**：2026-08
- **背景**：整份排行数据约 900KB，需要让所有用户读到最新版
- **决策**：数据文件上传云存储，数据库只存指针 `{fileID, lastUpdated}`
- **理由**：
  - `wx.cloud.callFunction` 返回值上限 **1MB**，整份数据回传会顶线
  - 前端直接写数据库单次 **512KB** 上限
  - 云存储单文件上限 50MB，够用
- **后果**：多一次 HTTP 下载；需要处理文件权限（见 ADR-002）

## ADR-002 云函数生成签名链接，而不是客户端直接下载

- **背景**：云存储默认权限「仅创建者可读写」，客户端 `downloadFile` 只有上传者能成功 →
  真实用户全部退回本地旧数据（表现为"别人看到的是上个月数据"）
- **决策**：`getRankings` 云函数在服务端调 `cloud.getTempFileURL`，返回签名链接；客户端用 `wx.downloadFile(url)`
- **理由**：云函数有完整存储权限，不受安全规则限制；签名链接可被任意客户端 HTTP 下载
- **被否决**：改存储权限为「所有用户可读」→ 基础版需付费
- **后果**：链接有有效期，每次打开都要调一次云函数（<1KB 返回，很快）

## ADR-003 上传云存储必须用唯一路径

- **日期**：2026-08-13（踩坑后）
- **背景**：同名覆盖 `rankings/rankings.json` 后，CDN 边缘节点仍返回旧内容，
  用户拿到几天前的数据，而数据库指针显示已更新
- **决策**：路径改为 `rankings/rankings-<日期>-<时间戳>.json`
- **理由**：CDN 对全新 URL 无缓存，直接回源
- **后果**：云存储会堆积文件（约 900KB/天，5GB 免费额度够用多年）

## ADR-004 arena.ai 被 Cloudflare 拦时，回退 HuggingFace 官方数据集

- **日期**：2026-11-15
- **背景**：arena.ai 全站 403，网页抓取完全失效；无头/有头/代理/换域名全部无效
- **决策**：新增 `fetch_lmarena_hf.py`，从 `lmarena-ai/leaderboard-dataset` 取数；
  `update.sh` 爬虫优先、失败自动回退
- **理由**：官方数据集每日更新、结构化（含置信区间/票数）、不受 Cloudflare 影响
- **代价**：缺 `image-to-webdev` 类目（用上次数据兜底）；需要代理
- **后果**：数据不再依赖单一网页源

## ADR-005 用 jsDelivr + 日期 tag 分发数据

- **日期**：2026-11-16
- **背景**：微信云函数在腾讯云境内，**访问 GitHub Pages 60 秒超时**（不是慢，是连不上）
- **尝试过的无效方案**：
  - 直接 GitHub Pages → 超时
  - `raw.githubusercontent.com` → 超时（被墙）
  - jsDelivr **分支 URL** → 可用但缓存 12 小时，数据看起来没更新
  - `data.jsdelivr.com` resolve API → 返回 `version: null`，拿不到 SHA
- **决策**：CI 每天给 data 分支打 tag `vYYYY-MM-DD`，云函数按「今天/昨天/前天」的 tag 取数
- **理由**：tag 是不可变 URL，每天一个新地址，**天然不会命中旧缓存**
- **后果**：CI 必须记得打 tag；没有当天 tag 时自动回退前一天
- **时区（2026-11-21 修正）**：tag 与 `lastUpdated` 统一用**北京时间**（CI 设置 `TZ=Asia/Shanghai`，云函数按 UTC+8 计算 tag 日期）。此前用 UTC 日期，18:00 UTC 触发会把数据标成前一天，云端按北京日期取不到「今天」的 tag；GitHub cron 延迟时更明显

## ADR-006 云函数超时在控制台设置，不在 config.json

- **背景**：`config.json` 里写 `"timeout": 60` 不生效，函数一直是默认 3 秒，
  下载 900KB 必然超时
- **决策**：在「微信开发者工具 → 云开发控制台 → 云函数 → 配置」改为 60 秒
- **注意**：重新部署**不会**重置该设置；如果发现又变 3 秒，去控制台改回
- **症状**：`errCode: -504003 | Invoking task timed out after 3 seconds`

## ADR-007 现阶段优先增长，不做广告变现

- **日期**：2026-11-16
- **背景**：累计 UV 33，流量主门槛需 500+；按当前量级广告月收益不足 10 元
- **决策**：30 天内不做广告，全部精力放在用户增长与留存
- **理由**：广告需要流量才有意义；早期加广告会伤害体验和留存
- **重新评估条件**：累计 UV > 500 且日均活跃 > 200

## ADR-008 建立 docs/ 文档机制

- **日期**：2026-11-16
- **背景**：项目里散落多份过时文档（有的描述与代码不符），且 AI 每次会话需要重新摸索，
  容易重复踩同样的坑
- **决策**：
  - `CLAUDE.md` 作为 AI 唯一入口，包含铁律与文档索引
  - `docs/` 为唯一权威文档源，旧文档标记为历史参考
  - 每个需求/功能一份文档，用固定模板
  - 重大技术选择追加 ADR
- **后果**：新增需求必须先写文档再写代码
