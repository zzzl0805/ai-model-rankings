# 发布流程

## 发布前检查清单

- [ ] `miniprogram/app.json` **不含** `pages/admin/admin`
- [ ] 数据是最新的（首页显示 ☁️云端 + 今天日期）
- [ ] 真机预览通过（扫码测试）
- [ ] 主包体积 < 2MB（开发者工具「详情 → 基本信息」查看）
- [ ] 无 console.log 调试残留
- [ ] 隐私政策页面可访问（`package-about/pages/privacy`）
- [ ] 新增的埋点事件已在后台创建（如本次有）
- [ ] 新增云函数已部署（v1.3 起含 `wxacode`，未部署时海报自动降级为文字落款）
- [ ] 《用户隐私保护指引》已声明「相册（仅写入）」（否则保存海报报 errno 112）。路径：mp.weixin.qq.com →「设置」→「服务内容声明」→「用户隐私保护指引」→ 去完善/更新；用途写「仅用于保存用户生成的图片到相册，不读取相册内容」
- [ ] 云开发控制台把 `wxacode`、`searchSubmit` 超时改为 20 秒（`config.json` 不生效，当前 3 秒）
- [ ] 微信搜一搜「内容接入」已开通：测试数据 → 审核 → 正式数据（见 docs/ops/search.md）
- [ ] 真机回归：保存海报到相册、分享图片；Android 后台状态点对比分享卡片（热启动）

## 步骤

### 1. 本地验证

```bash
# 开发者工具打开项目 → 自动编译
# 点「预览」→ 手机扫码 → 真机测试
```

重点测：
- 从分享卡片冷启动 → 详情页 → 返回（应回首页）
- 各 Tab 切换正常
- 首访提示条可关闭

### 2. 上传版本

> 开发者工具右上角 **「上传」**
> - 版本号：小修 `1.0.1`，新功能 `1.1.0`
> - 项目备注：写清本次改动

### 3. 设为体验版（推荐）

> mp.weixin.qq.com → 管理 → **版本管理** → 选中刚上传的版本 → **设为体验版**
> → 添加体验成员（自己 + 几个朋友先用）

### 4. 提交审核

> 版本管理 → **提交审核**
> - 功能页面：勾选本次改动的页面
> - 类目：与小程序实际服务一致
> - 测试账号：无需（无登录）

审核通常 **几小时到 2 天**。

### 5. 发布

审核通过 → 版本管理 → **发布**（可选全量或分阶段）

## 不需要审核的改动

| 类型 | 操作 |
|------|------|
| 数据更新 | 全自动，无需操作 |
| 云函数改动 | 开发者工具右键 → 上传并部署（立即生效）|
| 数据库/云存储 | 控制台操作 |

---

## 审核常见驳回（v1.3）

| 驳回理由 | 处理 |
|---|---|
| 隐私接口与实际声明不符（相册） | 确认《用户隐私保护指引》勾选「相册（仅写入）」且用途写明「仅写入、不读取」；代码只有保存海报一处调用 |
| 页面无法访问 / 白屏 | 新页面均已在 `app.json` 注册；体验版冷启动弱网时会先显示本地数据，不会白屏 |
| 功能不完整 / 含测试内容 | 「我的」三个空状态都有引导文案；落地页有完整榜单；海报失败会降级文字落款 |
| 分享图片不可用 | 保存相册需用户授权隐私弹窗；拒绝后降级为预览、长按保存，不会卡死 |
| 类目不符 | 保持原类目；新增页面不改变服务性质（工具/信息查询） |

审核期间不要修改代码或重复上传同一版本号，等结果即可。

## 云函数部署

```bash
# CLI 方式（需要开发者工具已登录）
/Applications/wechatwebdevtools.app/Contents/MacOS/cli \
  cloud functions deploy --env cloud1-d7g5tmh916383e8b5 \
  --names syncRankings --project <项目路径> --remote-npm-install
```

一次部署多个函数用 `--names a b c`。例如海报用的小程序码函数：

```bash
cli cloud functions deploy --env cloud1-d7g5tmh916383e8b5 \
  --names wxacode --project <项目路径> --remote-npm-install
```

⚠️ **部署不会重置超时设置**，但也不会应用 `config.json` 里的 timeout。
如果函数超时又变成 3 秒，去「云开发控制台 → 云函数 → 配置」改回 60 秒。
