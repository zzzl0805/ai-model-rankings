# 微信搜一搜接入 SOP

> 目标：把模型详情页/榜单页提交给搜一搜收录，获取自然搜索流量。
> 相关：`miniprogram/cloudfunctions/searchSubmit/`

## 0. 准入结论（2026-11-24，官方要求）

内容接入**个人主体申请不了**，同时要求：
- 非个人主体
- 月均 DAU ≥ 5000
- 以图文资讯内容为主营业务
- 开放类目仅限政务/部分商业服务/医疗/金融/部分文娱/社交笔记问答

本项目：个人主体、39 UV、工具类 → 不符合。**`submitPages` 暂停使用**，云函数保留但已移除定时器。

## 1. 后台开通（仅符合准入时）

mp.weixin.qq.com → 左侧「微信搜一搜」→「内容接入」→ 开通。

- 只有**已认证**的小程序能看到入口（本项目已认证）。
- 需要声明**内容类目**；类目提交后不可修改，每月仅一次机会，按实际内容选（AI/科技/工具类）。
- 开通后先用**测试数据**（`wxsearch_testcpdata`）推送，再到内容接入后台提交审核；搜一搜约 7 天内反馈。
- 审核通过后切换**正式数据**（`wxsearch_cpdata`）并再次提交审核，通过后才可能被线上搜到。

## 2. 云函数

`searchSubmit` 已部署，每天 09:30 提交最多 100 个页面：

- Top 60 文本 + 20 文生图 + 10 文生视频 + 10 图片编辑 + 5 图生视频 + 10 Agent
- 3 个榜单页 + 首页
- `path + query` 唯一；同一页面重复提交为覆盖更新

调用：

```js
// 默认：测试数据（内容接入审核通过前）
wx.cloud.callFunction({ name: 'searchSubmit', data: {} })

// 审核通过后：正式数据
wx.cloud.callFunction({ name: 'searchSubmit', data: { type: 'formal' } })
```

返回 `result.scopeDataErrmsg`：
- `该 appid 暂不允许推送数据` → 未开通内容接入 / 未审核通过
- 空 → 提交成功

⚠️ 云函数超时在控制台改（config.json 不生效），建议 **20 秒**。

## 3. 页面与文案要求（参考搜一搜官方教程）

- **昵称**：避免纯通用词；「AI模型排行」偏品类词，长期可考虑带品牌后缀，但改名需谨慎（影响已有分享/搜索）。
- **简介**：写清主体、功能、特色，不堆关键词。建议：
  > 聚合 LMArena 人类盲测 Elo 与各厂商 API 定价，覆盖文本、视觉、图像、视频等 12 个类目，帮开发者按场景和预算选模型，数据每日更新。
- **菜单/功能名**：用具体功能名（排行/对比/成本计算器/推荐/我的），不要「服务中心」这类宽泛词。
- **详情页**：标题带模型名 + 排名/价格；正文包含厂商、Elo、价格、上下文、模态，均有来源。
- **认证**：个人主体已认证，保留认证状态。

## 4. 找不到「内容接入」怎么办

先区分两件事：
- **允许被搜索 / 页面收录**：后台「页面内容接入 → 基础设置 → 页面收录」保持开启，微信爬虫会自动抓取；这是所有小程序都有的。
- **内容接入 / submitPages 主动推送**：只有部分认证账号/内容类目可见；个人主体+工具类很可能没有入口。

如果确认没有「内容接入」：
1. 不要继续等接口；把 `searchSubmit` 云函数保留但**不作为主路径**（定时器可暂停，避免无效日志）。
2. 改用**物理落地页**：Top 20 模型、8 个系列、5 个场景各做一个固定路径页面，标题/正文/内链完整，不依赖 query 参数。
3. 保证页面收录开关开启；用后台搜索词数据决定做哪些页面。
4. 分享/群/朋友圈仍可带新用户；搜索收录靠页面质量 + 时间。

## 5. 验收

- 后台「内容接入」显示审核通过。
- `searchSubmit` 返回 `scopeDataErrmsg` 为空。
- 搜一搜后台能看到搜索词/曝光；收录通常有 1–4 周延迟。
- 目标：6–10 周从 39 UV 到 500（自然搜索，无公众号）。
