# v1.6 全站 UI 升级：简洁、高级、美观、专业

> 状态：✅ 已实现（2026-11-26），v1.6.1 已上传（紧凑字号）
> 创建日期：2026-11-26
> 范围：所有用户可见页面（不含临时 admin 页）
> 前置：v1.5.2 已上线

## 1. 现状审计

- **主色不统一**：全局变量 `--color-accent #0F5EF0`，首页又用 `#2563EB`；紫色 `#7C3AED` 出现在标题/渐变/进度条中。
- **渐变过多**：14 处 `linear-gradient`，深蓝→紫、蓝→紫混用，视觉噪音大。
- **emoji 当结构图标**：详情分类、推荐场景、关于页功能、计算器场景名里大量 emoji，风格偏轻，不够专业。
- **字号/间距不统一**：20rpx 小字较多（10px），卡片圆角 12/16/20 混用，阴影深浅不一。
- **数据展示不统一**：名次有黄色徽标/斜体/普通数字三种；进度条渐变色；价格、百分比、票数格式各异。
- **头部不统一**：首页/我的深色渐变头，详情深色渐变 hero，落地页/预算页另一套渐变；原生导航与自定义导航混用。
- **页面覆盖**：9 个主页面 + 3 个榜单页 + 21 个模型固定页 + 8 个系列页 + 预算页 + 关于/隐私/导出。固定页共用模板，适合统一改造。

## 2. 设计方向

**“安静的数据终端”（Quiet Data Terminal）**

- 纸感浅底 + 墨色文字 + **唯一强调色**（品牌蓝）；不用紫色、不用装饰渐变、不用 emoji。
- 数据优先：名次、价格、变化用等宽数字与清晰层级表达，装饰元素让位。
- 高级感来自：留白、字号层级、细边框、克制的阴影、统一的圆角/间距，而不是渐变色块。
- 深色只用于“封面级”区域（首页/详情/落地页 hero），使用**纯墨色**而非渐变。

## 3. Design Tokens

### 3.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--ink` | `#0F172A` | 主文字、深色 hero |
| `--text-2` | `#5B6675` | 次级文字 |
| `--text-3` | `#8A94A6` | 说明/标签（仅在 ≥22rpx 使用） |
| `--line` | `#E9EDF2` | 分隔线/边框 |
| `--bg` | `#F7F8FA` | 页面底色 |
| `--surface` | `#FFFFFF` | 卡片 |
| `--accent` | `#0F5EF0` | 唯一强调色（链接/选中/数据） |
| `--accent-soft` | `#EEF3FF` | 选中底/标签底 |
| `--positive` | `#047857` | 上升/降价 |
| `--negative` | `#B42318` | 下降/涨价 |
| `--warning` | `#B45309` | 提示（少量） |

删除：`#7C3AED`、`#F59E0B` 作为主视觉、`#D97706`。

### 3.2 字号

| 级别 | 字号/行高 | 用途 |
|---|---|---|
| Display | 48/56 | 详情/落地页模型名 |
| H1 | 36/44 | 页面标题 |
| H2 | 30/38 | 卡片标题 |
| Body | 26/40 | 正文 |
| Meta | 22/30 | 厂商、来源、标签 |
| Micro | 20/28 | 仅脚注；不用于关键数据 |

数字统一 `font-variant-numeric: tabular-nums`。

### 3.3 间距/圆角/阴影

- 间距基数 8rpx；页面边距 24rpx；卡片内边距 28rpx；区块间距 24rpx。
- 圆角：卡片 16rpx；按钮/输入 12rpx；胶囊 999rpx。
- 阴影：仅固定底栏 `0 -2rpx 12rpx rgba(15,23,42,0.06)`；卡片用 1rpx 边框，不用阴影。

## 4. 组件规范

- **Header**：纯墨色（`--ink`）背景，H1 白字，日期 Meta 白 55%；无渐变。首页/我的/详情/落地页/预算统一。
- **Tabs/SubTabs**：白底；选中墨色 + 3rpx 蓝下划线；子 tab 选中 `--accent-soft` 底 + 蓝字。
- **Card**：白底、1rpx `--line` 边框、16rpx 圆角、28rpx 内边距；标题 30rpx/600，说明 22rpx。
- **List row**：上下 20rpx；名次 30rpx tabular；名称 30rpx/600；meta 22rpx；右侧分数 32rpx/700 蓝；分隔线 `--line`。
- **Rank**：普通数字；前三名仅用蓝色（不再黄底/斜体）。
- **Bar**：6rpx 轨道 `#ECEFF4` + 蓝色实心填充；无渐变。
- **Chip**：`--bg` 底 + `--line` 边框；选中 `--accent-soft` + 蓝字。
- **Button**：主按钮蓝底白字，高 88rpx，12rpx 圆角；次按钮白底细边框；文字按钮仅蓝字。
- **Empty/Loading**：文字 + 细线，不用 emoji；骨架屏使用浅灰块。
- **来源/免责**：Micro 字号、`--text-3`，行高 1.7。
- **移除 emoji**：页面结构标题、按钮、场景选择、关于页功能列表都不再用 emoji；分类/场景用文字标签。
  - 数据中的 emoji（`categories.icon`）不再渲染。
  - 关于页功能列表改为 `01–06` 编号。

## 6. 实施方式

1. **Token 层**：`styles/tokens.wxss`（CSS 变量）由 `app.wxss` 引入；各页用 `var(--...)`。组件（board）同样引入 token。
2. **共享样式**：`styles/model-landing.wxss`、`styles/board-page.wxss` 统一重写；生成页自动继承。
3. **主页面**：按流量优先级改造：
   - P0：首页、详情、落地页模板、预算页
   - P1：对比、计算器、推荐、我的、3 个榜单页
   - P2：方法论、关于、隐私、导出、海报
4. **app.json**：tabBar `selectedColor` 统一为 `#0F5EF0`；导航栏保持墨色。
5. **不改功能/数据**：只改视觉与文案排版；不新增入口、不改业务逻辑。

## 8. 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 数据密集页改动导致行高/对齐回归 | 可读性下降 | 先改首页/详情，截图逐页检查；保留 tabular 数字 |
| 去 emoji 后场景识别变弱 | 用户找不到功能 | 用文字标签/编号 + 副文案，不用图标 |
| 全局变量被页面局部覆盖 | 颜色不统一 | 逐页删除局部色板，统一 var |
| CSS 变量在组件内不继承 | 组件颜色异常 | 组件 WXSS 也引入 tokens，显式使用 |
| 全站改动范围大 | 审核/回归成本 | 分 P0/P1/P2 提交，一次发版但分批自测 |
| 包体积 | 超 2MB | 只改 CSS，预计 < +10KB |

## 10. 方案评审修订（2026-11-26，权威版本）

独立评审确认 7 项，以下覆盖前文：

### 10.1 主题：冷瓷感（B），不叫“纸感”
- `--bg #F6F7F9`、`--surface #FFFFFF`、`--line #E4E8EE`、`--ink #0F172A`、`--accent #0F5EF0`
- `--text-2 #5B6675`（5.8:1）、`--text-3 #66707C`（白底 4.7:1，仅白底使用）
- `#8A94A6`、`#94A3B8` **不再用于文字**，只做分隔/装饰
- 深色只用于：首页、详情、落地页、预算、榜单；对比/计算器/推荐/方法论/关于/隐私用浅色 masthead
- 「我的」保留墨色 header（tab 身份），但改纯色、无渐变

### 10.2 字号改用 px（物理字号稳定）
| 级别 | px/行高 | 用途 |
|---|---|---|
| Display | 30/38 | 详情/落地页模型名 |
| H1 | 22/30 | 页面标题 |
| H2 | 17/24 | 卡片标题 |
| Body | 15/24 | 正文 |
| Meta | 13/20 | 厂商/标签/来源 |
| Caption | 12/18 | 仅脚注/免责 |
| Data L | 32/40 | 主分数 |
| Data M | 26/32 | 价格/名次 |
| Data S | 20/28 | 行内数字 |

- 行高：正文 1.6，长文 1.7-1.8；Display 1.25。
- 数字：`font-feature-settings: 'tnum'` + 固定列宽/右对齐；不只依赖 `font-variant-numeric`。
- 不再使用 <12px 的文字。

### 10.3 Accent budget
每屏蓝色最多用于：选中态、主 CTA、至多一个关键数字/标记。
- 列表分数改 **ink 600 tabular**，不蓝色。
- 前三名用字重/大小区分（700 vs 400），不用黄底/蓝字。
- 进度条蓝填充可保留；同屏不再出现蓝色分数。
- 正/负/警告色只用于 delta 和状态。

### 10.4 Hero/Masthead
- 纯墨 `#0F172A`，高约 150-190px（含标题/sub），不放长描述。
- 落地页 hero：kicker「AI模型排行」+ 模型名（30px）+ 厂商/系列一行；description 移到第一张白卡。
- 详情 hero：模型名 + 厂商/系列 + badges，2rpx 蓝色底线。
- 榜单页 hero 保留标题 + 一行说明。
- 原生导航背景统一 `#0F172A`；非 tab 页保留原生导航（不全面 custom）。
- 导航标题：详情/落地页保留模型名（搜索价值）；榜单页用「榜单」避免与 hero 重复。落地页 hero 标题去掉「排名与价格」，只放模型名。

### 10.5 范围补漏
纳入：`components/board`、`components/poster`、`app.wxss` 的 `.card/.chip`、`app.json` 的 window/tabBar、`package-about` 白底、`package-export`。
- board：去 italic、去逐行阴影，Elo/名次改 ink，进度条统一。
- poster：去紫色渐变/金色/斜体，纯墨头 + 蓝线；生成三种海报人工验收。
- 组件内 CSS 变量继承不稳时使用固定色值 fallback。
