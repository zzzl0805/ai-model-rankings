# v1.8 首页吸引力与图标系统

> 状态：✅ 已实现，v1.8.0 已上传
> 日期：2026-11-26
> 基线：v1.7.1（深海军蓝 + 白卡 + 无衬线）
> 目标：不回到“控件堆叠”，但让首页**眼前一亮、有信息密度、分享入口明确、图标点睛**

## 1. 问题

用户反馈三条，都成立：

1. **首页排行分享/生成海报入口“没了”**：v1.7 为了简洁，把生成图片从首屏移到了列表底部“更多”，用户看不到。
2. **太寡淡**：去掉 emoji 后没有替代图标，全站只有文字和色块；TabBar 也是纯文字。
3. **首页不够抓人**：当前是一行筛选 + 列表，干净但缺少“今天有什么值得看”的信息密度。

不是要回到 v1.6 的 6 层控件；要加的是**内容**，不是**控件**。

## 2. 设计原则

- **加内容，不加控件**：首屏仍只有一行筛选；新增信息用一条概览 + 前三名强调表达。
- **分享入口必须在首屏**：header 右侧图标按钮，文字“海报”或“分享”，不再藏到列表底部。
- **图标统一一套**：线性、1.5px 描边、20px；只放在导航/操作/关键标记，不铺满列表。
- **信息密度靠数据，不靠标签**：用榜首、上升最快、样本最多、今日结论，而不是更多彩色 chip。
- **深海军蓝主色不变**；亮蓝只做链接/选中态；图标用墨色/灰色两套。

### 3.1 今日概览（一条，不占太多高度）

- 三个数据：**榜首 / 上升最快 / 样本最多**
  - 全部来自现有 rankings 数据，不新增抓取
  - 当前类目无 delta 时，第三项回退为“最高票”
- 一句 `conclusion`（已有数据）作为“今日结论”，放在概览里，不再只放列表底部
- 高度控制在 ~150rpx；不做轮播、不做多卡

### 3.2 前三名强调

- 名次 `01 / 02 / 03` 用 tabular，字号略大
- 第 1 名加一个**线性小皇冠/奖杯图标**（唯一彩色/墨色标记）
- 前三行模型名 16px/600；第 4 名起恢复 15px
- 不单独做“前三名卡片”，避免重复

### 3.3 分享 / 海报入口

- **masthead 右侧**：图标 + “海报”文字按钮，`bindtap=onGeneratePoster`
- 生成中显示“生成中…”，成功后 toast + 保存相册
- 列表底部保留“生成榜单图片”文字入口（长列表用户也能找到）
- 分享/海报数据与当前筛选一致；标题带当前类目/维度

### 3.4 列表

- 保持 v1.7 的两列栅格（左名次/模型/厂商，右 Elo/价格）
- 恢复 **delta** 的轻量展示（颜色 + 数字，不加底色）
- 不加回 CI/票数/代理 chip；这些留在详情
- 行高 18rpx，前三名可略高

## 4. 图标系统

### 4.1 规格

- 一套线性图标，1.5px 描边，圆角端点；不要混用实心/彩色/emoji
- 尺寸：TabBar 81×81（@3x 48pt），操作 20px，列表标记 16px
- 颜色：
  - 深海军蓝 `#0F172A`（选中/主操作）
  - 灰 `#7A8494`（默认/次级）
  - 亮蓝 `#0F5EF0` 只用于选中态的少量图标
- 本项目自绘线性图标，本地 PNG，不依赖外网
- 新增 `miniprogram/assets/icons/`，附 README

### 4.2 需要哪些

| 位置 | 图标 |
|---|---|
| TabBar | 排行（柱状）、对比（双列）、计算器、推荐（罗盘/星）、我的（人） |
| 首页 header | 分享/海报（图片+箭头） |
| 首页筛选 | 筛选（滑杆） |
| 首页第一名 | 皇冠/奖杯（仅 1 个） |
| 详情底栏 | 收藏（书签）、对比、图片 |
| 对比按钮 | 保存、生成图片 |
| 外链/复制 | 箭头、复制（少量） |

**不做的**：每个模型行都放行业图标、每个标题都放图标、彩色图标。图标是标点，不是装饰。

## 5. TabBar

- 原生 TabBar 增加 `iconPath` / `selectedIconPath`（10 张 PNG）
- 未选中灰 `#7A8494`，选中深海军蓝 `#0F172A`
- 不自定义 TabBar，避免同步/层级问题
- 审核和包体：10 张 81px PNG，预计 < 20KB

## 6. 实施顺序

1. **图标资产**：生成/引入 10 个 TabBar + 8 个操作图标；接入 TabBar 和首页/详情/对比
2. **首页**：masthead 海报按钮 + 今日概览 + 前三名强调 + delta 恢复
3. **分享闭环**：海报标题带当前榜单、生成中状态、保存相册 toast
4. **回归**：43 页、首页筛选/搜索/海报、375/390 截图
5. **版本**：1.8.0 上传 + 预览码

## 7. 验收

- [x] 前三名有明显但不浮夸的强调；不重复卡片

## 8. 风险

| 风险 | 对策 |
|---|---|
| 概览 + 前三名让首屏变重 | 概览限 150rpx；不加第二行筛选 |
| 图标风格不统一 | 只用一套线性图标；两种颜色 |
| TabBar 图标审核/包体 | 81px PNG、压缩；<20KB |
| 海报入口与底部入口重复 | header 主入口 + 底部文字入口，功能一致 |
| “上升最快”无 delta | 回退“最高票”，文案随数据切换 |
