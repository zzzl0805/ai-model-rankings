# v1.3 留存与增长方案

> 状态：✅ v1.3.0 已发布（2026-11-21），进入两周观察期
> 创建日期：2026-11-20
> 数据依据：累计 36 UV，近一个月 **90% 新用户来自搜索**

## 0. 判断

排行榜是"查完就走"的产品，不能指望日活。小程序又拿不到长期订阅消息，**无法主动把用户叫回来**。

所以留存只有一种形态：**用户下次有问题时，第一个想到你。**

三件事构成一个循环，现在断在第二环：

```
搜索面宽  →  更多人进来        ← 已在跑（90%）
留下资产  →  有理由回来        ← 缺失（本次重点）
可转发    →  带来新人          ← 部分（分享标题有了，图片没有）
```

## 1. 留下资产（最高优先级）

### 1.1 收藏模型

| 项 | 设计 |
|---|---|
| 存储 | `favorites: string[]`（模型 name） |
| 入口 | 详情页底部「⭐ 收藏」；首页顶部「我的」入口 |
| 页面 | 新增 `pages/mine/mine` |
| **回来的理由** | 收藏页显示每个模型**当前排名 + 价格 + 与你收藏时的变化** |

关键：不是"存一个列表"，是"存下来还会变"。
比如收藏页显示：「Claude Opus 5.5 综合 #4（↑2） · $4/$20（比上次 -$1）」。

### 1.2 对比组

现状：`compareList` 是匿名的 3 个模型，关掉就没了。

改造：

| 项 | 设计 |
|---|---|
| 存储 | `compareGroups: [{id, name, models: string[], savedAt}]` |
| 命名 | 默认「我的对比 1/2/3」，可改 |
| 操作 | 对比页「💾 保存这组对比」；已保存的组可切换、改名、删除 |
| 分享 | 分享时带上组名和模型 |

### 1.3 计算记录

| 项 | 设计 |
|---|---|
| 存储 | `calcHistory: [{model, inputTokens, outputTokens, costCNY, at}]`（保留最近 10 条） |
| 入口 | 计算器页底部「最近计算」 |
| 用途 | 他下次汇报或复用参数时直接调出来 |

## 4. 信息架构

```
首页
 ├─ 顶部「我的」入口 → pages/mine
 │     ├─ 我的收藏（带排名/价格变化）
 │     ├─ 我的对比组
 │     └─ 最近计算
 └─ 榜单 → 详情 → 收藏 / 加对比 / 生成图片

tabBar 保持 4 个不动（排行/对比/计算器/推荐）
```

**不加第 5 个 tab**：会压缩现有布局，且"我的"使用频率不适合放 tabBar。

---

## 5. 数据结构

```js
// 全部走 wx.setStorageSync，无后端改动
favorites:      string[]                              // 模型 name
compareGroups:  [{ id, name, models: string[], savedAt }]
calcHistory:    [{ model, inputTokens, outputTokens, costCNY, at }]  // 最多 10 条
```

**注意**：收藏页要显示"变化"，需要存快照：
```js
favoriteSnapshots: { [name]: { rank, priceInput, savedAt } }
```
回来时与当前数据对比，算出 ↑↓ 和价格变动。

**与方案的偏差**：
- 计算记录的展示入口放在「我的 → 最近计算」，未在计算器页底部重复展示（避免两处维护，且符合第 4 节信息架构）。
- 「价格变动」基于收藏时快照的单点对比，不是价格历史曲线（对应第 9 节未决项）。
- 落地页没有复用首页的完整交互，而是抽了轻量组件 `components/board`：落地页是固定视角，不需要切类目/维度/搜索，代码更小、渲染更快。

## 11. 审查修复记录（2026-11-20 第二轮）

对全量改动做了 4 维度审查 + 逐条对抗验证（10 条确认），已修复：

| 问题 | 修复 |
|---|---|
| 对比分享把模型名拼逗号串，名字自带逗号（全库 26 个）时被拆碎并污染接收方列表 | 改为 JSON 编码；接收端解析后按数据校验、去重 |
| 搜索/筛选态生成的海报把筛选子集当完整榜单 | 搜索或升序时禁止生成并提示 |
| 计算器「万token」按千token算，月费少 10 倍；记录单位矛盾 | 除数改 100；记录存绝对 token，展示为「万」 |
| 海报入口在 421 行列表底部不可达 | 提到列表上方快捷栏，与「更多榜单」并列 |
| 「我的」只索引 text.overall，11/12 类目收藏无排名/价格 | 索引全部类目（含子维度兜底），显示类目标签 |
| 收藏快照只有美元价，汇率波动被当成涨跌 | 快照存原生币种/来源/数据日期，同币种同来源才比较 |
| 落地页价格丢失代理/≈/币种标记，Qwen 人民币价显示「价格待补」 | 复用首页口径：$ / ≈$ / ¥、代理标记 |
| 落地页厂商按模型名猜，Microsoft/Bytedance 显示「其他」 | 共享 raw provider 映射表 |
| 首页/对比热启动点分享卡片不触发 onLoad，参数丢失 | App.onShow 缓存入口参数，页面 onShow 消费 |
| 小程序码固定开首页默认榜，与海报不一致 | 编程/国产/画图海报指向对应落地页，其余用 scene 编码类目/维度/视角 |
