# v1.7 品牌蓝专业版：结构性 UI 重做

> 状态：✅ 已实现，v1.7.1 已上传（深海军蓝主色）
> 创建：2026-11-26
> 线上基线：v1.5.2（v1.6.1 未提交审核）
> 目标：**简洁、美观、专业**，有明确主题色；不再使用“高级/纸感/衬线”这类容易跑偏的表述

## 1. 背景

v1.6 的失败不在执行，而在设计语法：深色 AppBar + 白卡 + 灰底 + 亮蓝 + 彩色标签，仍是通用 SaaS 后台。独立评审（设计总监/排版/信息架构/移动端）确认 9 项问题，核心是：

- 首页 6 层 chrome，数据首行在 1/3 屏以下
- 详情 11 个同权卡片，名次出现 3 次，96–100% 的进度条没有信息量
- 对比页模型名截断、半张表空值、整列绿底
- 标签通胀、颜色语义冲突
- 字号 1px 阶梯，12px 用了 120 处
- 列表行 5 个事实挤在一条线上，价格左右漂移
- 预算“前 97%”方向是反的

中途尝试过“纸白 + 衬线”的编辑风，被用户否决：AI 味重，且不是他要的方向。**最终回到有主题色的专业工具风。**

## 2. 设计语言：品牌蓝专业版

| Token | 值 | 用途 |
|---|---|---|
| `--navy` | `#0F172A` | 主色：导航、hero、主按钮 |
| `--blue` | `#0F5EF0` | 强调色：链接、选中态、少量标记 |
| `--ink` | `#0F172A` | 主文字、数据 |
| `--text-2` | `#5B6675` | 次级文字 |
| `--text-3` | `#7A8494` | 说明/单位/脚注 |
| `--bg` | `#F5F7FA` | 页面底色 |
| `--surface` | `#FFFFFF` | 卡片 |
| `--line` | `#E5EAF2` | 边框/分隔 |
| `--positive` | `#047857` | 上升/降价 |
| `--negative` | `#B42318` | 下降/涨价 |

- **字体**：无衬线（PingFang / HarmonyOS / system-ui），不用衬线。
- **字号**：Display 26 / H1 20–22 / H2 16 / Body 14 / Meta 12；数字 tabular。
- **卡片**：白底、1rpx 边框、12rpx 圆角、24rpx 内边距；无重阴影。
- **导航**：原生导航深海军蓝底白字；首页/我的自定义 header 同色。
- **TabBar**：原生，选中深海军蓝。
- **禁止**：紫色、装饰渐变、emoji、纸色、衬线、满格假进度条。

## 3. 页面改造

### 首页
- 6 层 chrome 压到 **一行筛选**：`类目 · 维度` + 搜索 + 地区。
- 类目/维度进底部 sheet，不再两排横滑 tab。
- 列表改 2×2 栅格：左列名次/模型/厂商，右列 Elo/价格，右缘对齐。
- 移除每行的 CI、票数、代理、样本少标签；进详情看。
- 海报/固定榜单/预算入口移到底部“更多”，不抢首屏。
- 结论保留一张白卡；脚注保留。

### 详情
- 蓝色 hero + 核心数据卡（Elo / 主榜 / 价格 / 上下文）。
- 区块从 11 个降到 6 个：定位、关键规格、榜单表现、分维度、优势与限制、同系列/竞品；公司/历程/来源折叠进“更多信息”。
- 名次只出现一次；进度条改成 `#rank/total + 前 X%`，不再用 96–100% 满格条。
- 价格来源/日期拆两行，避免日期断行。
- 底部固定操作：收藏 / 加入对比 / 生成图片。

### 对比
- 去掉页面内重复 masthead，直接用原生导航“AI大模型对比”。
- 模型名完整换行，不再截成 “Claude Opus 5....”。
- 只渲染至少两个模型有值的行；单边有数据不显示。
- best 只加粗，不做整列绿底；单边数据不标 best。

### 预算
- 结果卡三层：名字 + 月成本、场景/排名、价格/上下文 + 预算剩余。
- “前 97%”修正为 `rank/total` 的“前 3.1%”。
- 删除重复的 rank/cost 文案。

### 其余页面
- 计算器：成本改墨色（不再整列红），卡片细边框。
- 推荐：场景改两列卡片，减少滚动。
- 我的：蓝色 header + 白色列表。
- 榜单/落地页：蓝色 hero，列表/卡片统一；落地页排名条改百分位。
- 方法论/关于/隐私/导出：统一浅灰底、白卡、蓝色链接；关于页 mark 改品牌蓝。
- 海报 canvas：头部改品牌蓝 + 白色分隔线。

## 5. 风险/回滚

- 用户已否决 v1.6.1：**不要提交 1.6.1**；线上保持 1.5.2，直到 1.7.0 审核通过。
- 蓝色导航对“关于/方法论”等长文页可能偏重；保留原生返回，内容区仍白底。
- 详情删减了部分卡片；完整信息仍在“更多信息”折叠区。
- 落地页/榜单共用模板，改样式会影响 29 个固定页，已用模板级回归覆盖。
