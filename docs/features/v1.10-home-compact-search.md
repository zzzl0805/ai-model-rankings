## 2. 根因

### 2.1 数据没更新

- GitHub Actions 今天的定时任务延迟到 **09:38** 才完成
- `syncRankings` 在 **09:00** 已检查过，下一次要到 15:00

修复：

- 手动触发 `syncRankings`，云端已到 **2026-11-27**
- 定时触发器从每天 4 次改为 **每小时检查**（`0 0 * * * * *`），已重新部署
- 数据没变时函数幂等跳过，不重复上传

### 2.2 搜不到混元4

- `Hy4` / `混元4` 在最新数据里存在，排名 **WebDev #26 / Agent #21**
- 它不在 `text` 类目；原搜索只在**当前类目**里过滤，所以在文本榜搜「腾讯」永远看不到它

修复：

- 搜索改为**跨全部类目**（取各类目 overall）
- 结果按类目内名次排序，并在行内显示「腾讯 · WebDev」这类类目标签
- 搜索 `腾讯` / `混元` / `混元4` / `Hy4` 均能找到混元4
