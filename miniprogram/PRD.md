# AI模型排行 — 产品需求文档 (PRD)

## 产品概述
帮开发者选择最合适的AI大模型的微信小程序。

## 核心数据
- 数据源：`data/models.json`，内嵌 20 个模型
- 每个模型包含：名称、厂商、标签、7维评分、定价、技术规格、优缺点、竞品

## 功能清单

### Tab 1: 排行 (pages/index)
- [ ] 顶部品牌栏：标题 + 副标题
- [ ] 分类切换栏：综合/编程/推理/写作/中文/多模态/性价比（横向滚动）
- [ ] 模型列表：排名序号 + 名称 + 厂商 + 分数
- [ ] 点击跳转详情页
- [ ] 下拉刷新
- [ ] 加载态 / 空态 / 错误态

### Tab 2: 对比 (pages/compare)
- [ ] 模型选择区：最多3个槽位 + 添加按钮
- [ ] 添加模型：底部弹窗 Picker，支持搜索
- [ ] 对比表格：12行属性 × N列模型，最优绿色高亮
- [ ] 移除模型
- [ ] 导出功能（跳转导出页）

### Tab 3: 计算器 (pages/calculator)
- [ ] Token 输入框
- [ ] 输出:输入比例选择（1:1 ~ 4:1）
- [ ] 快捷预设（轻度/中度/重度/企业级）
- [ ] 厂商筛选栏
- [ ] 成本列表：模型名 + 月费 + 年费 + 进度条
- [ ] 点击跳转详情页

### Tab 4: 推荐 (pages/recommend)
- [ ] 场景网格：8个场景卡片（写代码/推理/写作/中文/多模态/省钱/速度/隐私）
- [ ] 选择场景后展示 Top 3 推荐模型
- [ ] 每个模型显示：奖牌 + 名称 + 厂商 + 推荐分 + 综合/编程/推理/性价比分数
- [ ] 一键加入对比
- [ ] 返回场景选择

### 详情页 (pages/detail)
- [ ] 模型头部：名称 + 厂商 + 综合分 + 标签 + 收藏 + 分享
- [ ] 适用场景列表
- [ ] 各维度评分条形图（可点击查看数据来源）
- [ ] 优缺点对比
- [ ] 技术规格
- [ ] 定价信息
- [ ] 竞品列表（可跳转对比）
- [ ] 成本计算器入口

### 分类页 (pages/category)
- [ ] 分类标题 + 描述
- [ ] 按评分/价格排序切换
- [ ] 模型列表

### 方法论页 (pages/methodology)
- [ ] 静态内容：评分来源说明

## 技术约束
- 纯微信小程序（不用框架）
- 数据内嵌 JSON，无网络请求
- 纯 JS（不用 TypeScript）
- 兼容 ES5 语法（不用 ?. ?? 等新语法）
