# AI模型排行 — 优化方案 v4

## 问题清单

### 1. TabBar 图标显示黑框
- **原因**：`assets/tabbar/*.png` 只有 126 字节，是空白占位图
- **修复**：生成正确的 81×81 PNG 图标

### 2. Agent 排行榜用百分比而非 Elo
- **原因**：LMArena Agent 评测用不同指标（净提升%、确认成功%等）
- **修复**：Agent 大类单独处理，显示百分比指标，不参与 Elo 对比

### 3. 没有数据的维度仍显示
- **原因**：维度列表固定 8 个，不检查是否有数据
- **修复**：动态过滤，只显示有数据的维度

### 4. 模型名称下方缺少公司名
- **原因**：排行列表只显示模型名
- **修复**：在模型名下方显示 provider（公司名）

### 5. 排行页不支持搜索
- **原因**：当前没有搜索功能
- **修复**：顶部增加搜索框，支持按模型名或公司名搜索

### 6. 对比页添加模型 Bug
- **原因**：`onSelectModel` 用 `e.currentTarget.dataset.name` 获取名称，但 wxml 绑定的是 `data-name`，可能不匹配
- **修复**：检查 wxml 和 js 的数据绑定一致性

### 7. 不支持正序/倒序
- **原因**：排行固定按 Elo 从高到低
- **修复**：增加排序切换按钮（正序/倒序）

### 8. 计算器页支持价格排行
- **原因**：当前只有成本列表
- **修复**：增加按价格排序的排行视图
